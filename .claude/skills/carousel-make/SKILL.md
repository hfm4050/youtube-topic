# 캐러셀 자동 제작

입력은 셋 중 하나: (a) refs의 캐러셀 후보(`collect.py list --status 검수대기`에서 🎠), (b) 분석이 끝난 레퍼런스(`reels/data/analysis/<id>/analysis.md`), (c) 이번 주 CSV 주제(`work/out/전체7개채널_63개주제_*.csv`의 한 행) 또는 사용자가 준 주제.

## 순서
1. 채널과 주제 한 줄을 확정한다. 레퍼런스에서 올 때는 **구조만 빌리고 내용은 우리 분야로 새로 쓴다**(원본 문장·디자인을 옮기지 않는다).
2. 사실 확인: 숫자·법 조항·제도는 WebSearch로 출처를 확인하고 스펙의 `sources`에 URL을 적는다. 확인 못 한 수치는 쓰지 않는다.
3. `reels/specs/<날짜>_<채널>_<slug>.json` 작성. 형식은 `reels/scripts/carousel_render.py` 머리말과 `reels/specs/sample_claim-3years.json`.
   - 6~8장. 1장 cover(멈추게 하는 한 문장, 핵심어는 `**강조**`) → 본문은 **한 장 한 메시지** → 마지막 cta(저장·공유·댓글 중 하나만).
   - 제목 28자 이내, 본문 120자 이내, 목록은 3~4개. 테마는 채널당 하나로 고정해 계정 톤을 맞춘다(기본 paper).
   - 장 구성은 내용에 맞는 타입을 고른다: 순서·이유 = point, 준비물·자가 점검 = checklist, 둘 중 고르기 = compare, 전문가 한 마디 = quote.
4. `python3 reels/scripts/carousel_render.py <spec>` — 경고(⚠)가 나오면 고쳐서 다시. 금지 표현·채널 금지 테마는 오류(✖)로 멈춘다.
5. 결과 PNG를 Read 도구로 **직접 본다**: 글자 넘침, 줄바꿈 어색함, 강조 색 과다를 확인하고 고친다.
6. 보고: 폴더 경로, 장 수, 캡션, 출처, 사람이 확인할 것(의료·보험 문구 자문, 실제 사례 여부).

## 자동 제작 모드 (아침 예약 실행)
캐러셀 후보마다 1~5를 돌려 `reels/out/carousel/`에 **대기**시킨다. 하루 최대 5개. 업로드는 하지 않는다 — 인스타 인기 음원은 앱에서만 붙일 수 있고, 의료·보험 문구는 발행 전 사람 검수가 필요하다.

## 노션 등록 (선택)
사용자가 보관할 노션 위치를 지정한 경우에만: 페이지를 만들고 PNG를 `notion-create-attachment`로 올린 뒤 원본 레퍼런스 링크·캡션·출처를 본문에 넣는다. 위치가 정해지지 않았으면 만들지 말고 물어본다. '건강한마케팅 — 전체 채널' 페이지 본문은 화요일 발행 절차(replace→insert) 외에는 건드리지 않는다.
